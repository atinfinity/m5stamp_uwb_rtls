```
(sync_analysis.py の出力貼付)

```

- [ ] **σ < 2 ns**(≈ 60 cm 相当、tdoa-design.md §6 の 2. の目標)
- σ が 2〜10 ns の場合: TCXO 化・ブリンク間隔短縮での改善余地を検討
